# Фронтенд: текущее состояние

Каталог `client/`. Это кликабельный прототип на моках (этап 1 из ТЗ). Бэкенда нет, все данные лежат в `localStorage`. Подробный README с правилами на украинском: `client/README.md`.

## Стек

React 19, Vite 8, TypeScript 6, Tailwind v4 (`@tailwindcss/postcss`), React Router 7, Recharts 3, lucide-react. Примитивы UI (`components/ui`) написаны вручную в стиле shadcn, без Radix и без CLI shadcn. Алиас `@/*` указывает на `src/*` (в `tsconfig.app.json` только `paths`, без `baseUrl`, он устарел в TS 6).

## Маршруты

`/login`, `/` (dashboard), `/orders`, `/orders/:id`, `/purchases`, `/purchases/new`, `/purchases/:id`, `/inventory` (Склад), `/suppliers`, `/categories`, `/analytics`, `/audit`, `/users`, `/integration`, `/settings`. Старый `/unallocated` перенаправляет на `/inventory`. Доступ закрывают `RequireAuth` и `Guard(permission)`; на сервере то же должно проверяться заново.

## Права

`purchases.view`, `purchases.create`, `allocations.create`, `allocations.edit_closed`, `inventory.manage`, `reports.view`, `reports.export`, `users.manage`, `settings.manage`. Роль admin имеет все, executor: `purchases.view`, `purchases.create`, `allocations.create`. Менеджерские права добавляются через `extraPermissions` пользователя.

## Данные и логика: слой API

Страницы и компоненты работают с данными **только через `src/api`** (правило ESLint запрещает импорт `@/api/mock/*` снаружи). Объекта базы они не видят.

- `api/contract/`: контракт. `types.ts` (сущности), `dto/*.ts` (входы и ответы, уже посчитанные «сервером»: суммы, статусы, названия, флаги `locked`), `client.ts` (интерфейс `ApiClient`, по подинтерфейсу на модуль бэкенда из `03-backend-plan.md`), `result.ts` (`ApiResult<T>`: нарушение бизнес-правила приходит как `{ ok: false, error }`, не исключением), `constants.ts` (таблица роль → права, `EMPTY_FILTER`).
- `api/hooks/`: хуки TanStack Query (`useStock`, `useCreatePurchase`…). Каждая мутация инвалидирует ровно те данные кэша, которые могла изменить (`invalidate.ts`, ключи в `keys.ts`). `lib/use-single-flight.ts` защищает записи от двойного клика.
- `api/active-client.ts`: **единственная точка замены** мока на настоящий сервер.
- `api/mock/`: вся имитация сервера, заменяется целиком:
  - `storage.ts`: база `Db` одним синглтоном в `localStorage` (`mlt-oblik:db:v1`, пользователь `mlt-oblik:user:v1`); `runOp` клонирует базу и фиксирует изменения только при `ok`;
  - `handlers/*`: реализация `ApiClient` по модулям, задержка сети (`VITE_MOCK_LATENCY_MS`, по умолчанию 150 мс), определение действующего пользователя;
  - `engine/*`: бизнес-логика (бывший `domain/`): FIFO, склад, закупки, вложения, корректировки, отчёты, права, аудит. Комментарии на украинском, это то, что уйдёт на сервер вместе с тестами;
  - `seed/*`: демо-БД, разбитая по сущностям; события воспроизводятся теми же операциями движка: 18 товаров, 5 поставщиков (один неактивный), 16 заявок, 11 закупок, 29 вложений. Заявка `o15` имеет намеренно не замапленный статус `on-hold`. Демо-пользователи: `u_admin`, `u_master`, `u_manager`, `u_master2`.
- Деньги: целые копейки в полях `*Kop`; количества округляются `roundQty` (в движке).
- Чтобы подключить сервер: написать HTTP-реализацию `ApiClient` (например, `api/http/`) и экспортировать её из `api/active-client.ts`. Страницы не меняются.

## Склад и закупки (актуальная логика)

- На странице «Склад» одна таблица товаров: остаток, средняя цена, стоимость, статус. В строке кнопки «Розподілити» (диалог `components/allocation/allocate-product-dialog.tsx`, цена по FIFO), «Поповнити», корректировка остатка (право `inventory.manage`).
- Страница «Нова закупівля» всегда создаёт закупку на склад. Закупка «в заявку» создаётся только из `components/allocation/add-allocation-dialog.tsx` внутри карточки заявки.
- В закупках колонка «Залишок на складі», на dashboard одна цифра стоимости склада. Функции в `api/mock/engine/purchases.ts` и `reports.ts`: `purchaseRemainingKop`, `allocatedVsStock`.
- Закрытая заявка (вложения блокируются) только в статусе «Видано». «Готово» не блокирует. Статусы приходят только из RO App.
- Корректировка остатка не уводит склад в минус (никогда). Это отдельная операция «Коригування»; её партия учитывается в сверке отдельным слагаемым.
- Купить новый товар сразу в заявку из диалога вложения можно одной атомарной операцией (позиция закупки с `newProduct`).

## Тема

Токены CSS в `src/index.css` (`:root` и `.dark`), палитра: `#06141B #11212D #253745 #4A5C6A #9BA8AB #CCD0CF`. По умолчанию тёмная тема. Два вспомогательных токена `--success` и `--warning` нужны только для бейджей статусов. Цвета только через токены.

## Правки в очереди (по замечаниям разработчика)

- Переделать мобильный дизайн (не устраивает). Сейчас мобильный режим: `UiProvider.forceMobile` показывает рамку телефона 390px, `isNarrow` при ширине менее 768px, навигация мастера `MOBILE_NAV_ITEMS` из двух разделов.
- Прочие мелкие правки: разработчик назовёт отдельно.
- После готовности API: шаг 12 из `03-backend-plan.md` теперь сводится к написанию `api/http` по контракту (`api/contract/client.ts` и `dto/*`) и замене экспорта в `api/active-client.ts`. localStorage останется только для темы.

## Тесты

`npm test` (Vitest, без DOM): тесты движка `api/mock/engine/*.test.ts` и демо-данных. Главный: `invariants.test.ts` прогоняет воспроизводимые случайные последовательности из 300 операций на демо-БД и после каждого шага проверяет инварианты (остаток не отрицательный, сверка склада с закупками плюс партии-корректировки, количества и суммы вложений равны сумме их строк, цены партий не меняются, финансовые записи не исчезают). Эти тесты переедут на сервер вместе с движком. Тестов интерфейса, хранилища и хуков нет, они проверяются руками по сценариям.

## Известные ограничения прототипа

- Нет серверной проверки прав (UI только прячет кнопки), нет транзакций и блокировок, нет idempotency на сервере (защита от двойного клика сделана в интерфейсе).
- Синхронизация RO App (`api/mock/engine/integration.ts`, `syncRoApp`) только симулируется и на сервер не переносится.
- Страницы получают списки целиком; пагинация и серверная сортировка добавляются при подключении настоящего API.
