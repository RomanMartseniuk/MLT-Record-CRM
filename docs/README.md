# Документация MLT Облік

Порядок чтения для Claude Code:

1. `01-idea.md` — что за проект, зачем он, что решено и как мы к этому пришли.
2. `02-spec.md` — полное ТЗ (v1.1). Источник требований.
3. `03-backend-plan.md` — модули бэкенда, инварианты, пошаговый план. Бэкенд разработчик пишет сам.
4. `04-frontend-status.md` — что уже сделано во фронтенде, как он устроен, какие правки в очереди и что уйдёт на сервер.
5. `05-source-description.md` — исходное описание разработчика (справочно).

Правило: при расхождении `02-spec.md` с кодом верно ТЗ, если в «Журнале изменений» нет другого решения. Если требование неясно, спросите разработчика, не угадывайте.
